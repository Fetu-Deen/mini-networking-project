# A mini project on Networking

A hands-on DevOps project focused on deploying a simple website using Amazon EC2, DNS, and web server configuration.

## Project Overview

This project demonstrates how to deploy and expose a simple website using AWS infrastructure and a custom domain.

The goal is to understand the complete journey from domain registration to a publicly accessible website.

## Objectives

- Configure a custom domain.
- Launch and configure an EC2 instance.
- Understand DNS resolution and domain delegation.
- Configure Nginx as a web server.
- Connect the domain to the EC2 instance.
- Configure HTTPS.
- Document infrastructure, deployment, and troubleshooting.

## Architecture

**Planned architecture:**

User → DNS → Amazon EC2 → Nginx → Website

The domain is registered through Porkbun, while AWS is used for infrastructure and hosting.
